# Demo screenshots

These images show actual command-line runs of the scripts in this repository.

- Authentication and network examples use the synthetic CSV files committed here.
- The HTTP header checker made one real request to a temporary local HTTP server.
- The TLS inspector made a verified connection to a temporary local TLS server using a short-lived certificate trusted only during that demo.
- The file-integrity demo created a baseline, then added, changed, and removed test files.
- The phishing URL tool parsed a reserved TEST-NET address locally; it did not visit the URL.
- The password generator used Python's `secrets` module. Its generated demo credential is redacted in the screenshot and must not be reused.

These are local demonstration captures, not evidence of a production assessment or a third-party security audit.
