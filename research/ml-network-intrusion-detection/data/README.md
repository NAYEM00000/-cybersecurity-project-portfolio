# Dataset instructions

Download the official UNSW-NB15 training and testing CSV files from:

https://research.unsw.edu.au/projects/unsw-nb15-dataset

Place them here:

- `raw/UNSW_NB15_training-set.csv`
- `raw/UNSW_NB15_testing-set.csv`

Do not commit the raw dataset to this repository. The official dataset page describes academic-use conditions and the papers that must be cited. Keep the original files unchanged and record their SHA-256 hashes in your experiment run log.

Expected official split sizes are documented by UNSW as 175,341 training records and 82,332 testing records. If your files have different dimensions, record the reason and inspect the files before proceeding.
